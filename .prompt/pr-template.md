### 🧪 테스트 방법
1. `npm run dev`로 개발 서버 실행
2. localhost:3000에서 Header 컴포넌트 확인
3. 화면 크기 조절하여 반응형 동작 확인
4. 사용자 프로필 드롭다운 클릭하여 메뉴 동작 확인
